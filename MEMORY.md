# MEMORY.md

Standing rules for working on this repo, kept separate from `CLAUDE.md` (architecture/internals reference) and
`README.md` (human-facing quick-start).

- Keep `CLAUDE.md` and `README.md` up to date as part of any change, not as a follow-up — update whichever of
  them describes the thing you just changed (module options/behavior/internals → `CLAUDE.md`; the flake's public
  usage, `just` commands, or quick-start → `README.md`) in the same commit.
- Keep this file (`MEMORY.md`) itself up to date too — when a new standing rule for working on this repo comes
  up, add it here rather than letting it live only in conversation.
